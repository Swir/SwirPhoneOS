# Branding

`swirphoneos.svg` is the original vector application icon for this foundation. It is a design asset, not a screenshot of a working OS or installer. Generate platform PNG/ICO sizes from this source when packaging the actual GUI. No font or third-party image asset is bundled.

Visual direction: dark navy, electric blue/cyan, clean readable controls and restrained neon accents. Accessibility and readability take priority over decoration. Planned future assets include launcher icons, boot animation and wallpapers; those are not implemented by this SVG.
