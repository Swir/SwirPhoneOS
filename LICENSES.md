# Licensing Strategy

No Android/kernel/vendor code is imported by this foundation. Preserve upstream notices when adding components and select/document the license for original code before binary distribution. This policy is not a blanket license grant for future AOSP, Linux or vendor material.

Track Linux kernel and AOSP component obligations separately. Never redistribute proprietary firmware or vendor blobs without permission. Keep signing keys private. The application icon is original project artwork; no fonts are bundled.
